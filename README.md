# IRIS Pay платежен модул за PrestaShop
**Версия:** 1.0.0
**Изисква PrestaShop:** 8
**Лиценз:** GPLv2 или по-нов
---
## Описание
Платежният модул IRIS Pay за PrestaShop позволява на търговците да приемат сигурни онлайн плащания чрез Open Banking технологията на IRIS Solutions.
Модулът осигурява безпроблемна интеграция с PrestaShop, като поддържа:
- обработка на транзакции в реално време
- автоматично обновяване на статусите на поръчките
- сигурна комуникация с IRIS Pay API
---
## Функционалности
- Обработка на плащания чрез IRIS Solutions
- Интеграция с PrestaShop checkout
- Поддръжка на тестова (Sandbox) и продукционна (Live) среда
- Лесна конфигурация през административния панел
---
## Изисквания
- PrestaShop 8
- Активен търговски акаунт в IRIS Pay
- Валидни идентификационни данни (API Key)
- SSL сертификат (HTTPS е задължителен)
---
## Инсталиране на модула
1. Свалете модула в `.zip` формат от:
….
2. Влезте в административния панел на вашия PrestaShop магазин
3. Отидете в:
**Modules → Module Manager → Upload a module**
4. Качете `.zip` файла
5. Намерете модула **"Iris Pay Payment"** в категория **Payments**
6. Натиснете **Install**
> ℹ️ След инсталация модулът се активира автоматично. Може да го деактивирате временно от съответния бутон.
7. След приключване натиснете **Configure**, за да отворите настройките
---
## Конфигуриране на модула
1. Регистрирайте акаунт и вземете уникален ключ от **Портала за търговци**
2. Отидете в:
**Modules → Module Manager**
3. Филтрирайте:
**Category → Payments**
4. Намерете **IRIS Pay** и натиснете **Configure**
5. Въведете получения API Key (Уникален ключ) в полето API Key
6. Запишете промените
---
## Общи настройки
### Environment (Среда)
Превключване между:
- Sandbox (тестова среда)
- Live (продукционна среда)
### SDK Version (SDK версия)
- Developer
- Production
### API Key
Уникален ключ (напр. `2b473c0e-7440-4325-aa75-a72ae9a58b49`)
---
⚠️ **Важно:**
Уверете се, че сте изключили тестов режим (Sandbox), преди да започнете да приемате реални плащания.
---
## Процес на плащане (Payment Flow)
1. Клиентът избира **IRIS Pay (Open Banking)** при checkout
2. Потвърждава поръчката
3. Зарежда се IRIS Pay SDK
4. Клиентът избира банка
5. Данните се изпращат към IRIS Pay API
6. Клиентът завършва плащането
7. Поръчката се създава в PrestaShop
